VBit Inlay - Create VCarvings and VCarve Inlays in [Autodesk Fusion](https://www.autodesk.com/products/fusion-360) for CNC Woodworking.

- Automatically create the proper toolpaths for flat inlays, such as cutting boards
- Create advanced 3D inlays on curved and non-planer surfaces
- Vector editing tools to create clean vector designs for CNC work
